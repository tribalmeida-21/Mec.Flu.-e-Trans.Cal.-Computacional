# Mec.Flu.-e-Trans.Cal.-Computacional
Repositório com os trabalhos desenvolvidos para a disciplina de Mecânica dos
Fluidos e Transferência de Calor Computacional (EEK 597) — Engenharia
Mecânica, UFRJ.

## Trabalhos

### Trabalho 1 — Gerador de Malhas
Gerador de malhas 1D e 2D com distribuição uniforme e aleatória, com
elementos triangulares ou quadrangulares no caso 2D. Calcula a
área/comprimento de cada elemento e as estatísticas de qualidade da malha.

### Trabalho 2 — (Código MEF)
Foi realizada simulações de corrente vorticidade de um escoamento 2D se utilizando do metodo de elementos finitos
analisando para cilindro, aerofolio, losango.

## Requisitos
- Python 3
- NumPy
- Matplotlib
